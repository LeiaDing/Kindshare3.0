## 📍 钱包连接阶段流程（⭐ 这里才铸造代币）

```
┌─────────────────────────────────────────────────────────────────────┐
│ 用户在前端点击 "连接钱包" 按钮                                        │
│ （可能在 Profile.jsx、Home.jsx 或其他页面）                          │
└────────────────────────────┬────────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────────┐
│ 前端: useWeb3.js Hook (或者页面中的代码)                            │
│ ─────────────────────────────────────────────────────────────────── │
│ const connectWallet = async () => {                                │
│   try {                                                            │
│     // 1️⃣ 检查是否安装了 MetaMask                                  │
│     if (!window.ethereum) {                                        │
│       alert('请安装 MetaMask 扩展');                               │
│       return;                                                      │
│     }                                                              │
│                                                                     │
│     // 2️⃣ 创建 ethers.js 浏览器提供者                              │
│     const provider = new ethers.BrowserProvider(window.ethereum); │
│                                                                     │
│     // 3️⃣ 请求用户授权访问 MetaMask 账户                           │
│     const accounts = await window.ethereum.request({              │
│       method: 'eth_requestAccounts'                               │
│     });                                                            │
│     // MetaMask 弹出授权对话框 ◄──── 用户选择要连接的账户           │
│                                                                     │
│     // 4️⃣ 获取用户选择的账户地址                                   │
│     const account = accounts[0];                                  │
│     // account = "0x742d35Cc6634C0532925a3b844Bc9e7595f..."       │
│                                                                     │
│     return account;  ◄──── 返回钱包地址给页面                      │
│   } catch (error) {                                               │
│     console.error('连接失败:', error);                            │
│   }                                                                │
│ };                                                                 │
└─────────────────────────────┬───────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────┐
│ MetaMask 浏览器扩展                                                  │
│ ─────────────────────────────────────────────────────────────────── │

│ │ KindShare 请求连接到 MetaMask                              │   │
│ │                                                             │   │

│                                                                     │

│ MetaMask 返回选中的账户地址数组: ["0x742d35Cc6634C0532925a..."]   │

                    POST /api/v1/wallet/connect

                   + JWT Token (Cookie)

┌─────────────────────────────────────────────────────────────────────┐
│ 前端: Redux web3Api.js                                              │
│ ─────────────────────────────────────────────────────────────────── │
│ connectWallet: builder.mutation({                                  │
│   query: (data) => ({                                              │
│     url: '/wallet/connect',                                        │

└─────────────────────────────┬───────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────┐
│ 后端: 中间件 auth.js → isAuthenticatedUser                          │
│ ─────────────────────────────────────────────────────────────────── │
│ export const isAuthenticatedUser = async (req, res, next) => {     │
│   try {                                                            │
│     // 从 Cookie 获取 JWT Token                                    │
│     const { token } = req.cookies;                                │
│                                                                     │
│     if (!token) {                                                  │
│       return next(new ErrorHandler("Login first", 401));          │
│     }                                                              │
│                                                                     │
│     // 验证并解码 Token                                             │
│     const decodedData = jwt.verify(                               │
│       token,                                                       │
│       process.env.JWT_SECRET                                      │
│     );                                                             │
│     // decodedData = { id: "673f2b4c1a2b3c4d5e6f7g8h" }           │
│                                                                     │
│     // 从 MongoDB 获取用户信息                                      │
│     req.user = await User.findById(decodedData.id);              │
│     next();                                                        │
│   } catch (error) {                                               │
│     return next(new ErrorHandler(error.message, 401));            │
│   }                                                                │
│ };                                                                 │
│                                                                     │
│ 中间件完成: req.user 包含当前登录用户的信息                          │
└─────────────────────────────┬───────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────┐
│ 后端: web3Controllers.js → connectWallet()  ⭐ 核心函数             │
│ ─────────────────────────────────────────────────────────────────── │
│                                                                     │
│ export const connectWallet = catchAsyncErrors(async (req) => {    │
│   const { walletAddress } = req.body;                             │
│   // walletAddress = "0x742d35Cc6634C0532925a3b844Bc9e7595f..."  │
│                                                                     │
│   // ✅ 第 1 步: 验证钱包地址格式                                   │
│   if (!walletAddress) {                                           │
│     return next(new ErrorHandler("Wallet required", 400));        │
│   }                                                               │
│                                                                     │
│   if (!isValidEthereumAddress(walletAddress)) {                   │
│     return next(new ErrorHandler("Invalid address", 400));        │
│   }                                                               │
│   // ✅ 验证通过 (使用 ethers.isAddress() 验证)                     │
│                                                                     │
│   // ✅ 第 2 步: 检查钱包是否已被其他用户使用                        │
│   const existingUser = await User.findOne({ walletAddress });    │
│   if (existingUser && existingUser._id !== req.user._id) {       │
│     return next(new ErrorHandler(                                │
│       "This wallet is already connected",                         │
│       400                                                         │
│     ));                                                            │
│   }                                                               │
│   // ✅ 钱包未被其他用户使用，可以继续                              │
│                                                                     │
│   // ✅ 第 3 步: 更新 MongoDB 中的用户钱包地址                      │
│   const user = await User.findByIdAndUpdate(                      │
│     req.user._id,                                                 │
│     { walletAddress },                                            │
│     { new: true }  // ◄──── 返回更新后的文档                      │
│   );                                                              │
│   // MongoDB 更新:                                                │
│   // db.users.updateOne(                                          │
│   //   { _id: ObjectId("673f2b4c1a2b3c4d5e6f7g8h") },             │
│   //   { $set: { walletAddress: "0x742d..." } }                   │
│   // )                                                            │
│                                                                     │
│   // ✨ ✨ ✨ 第 4 步: 铸造 100 个代币给用户 ✨ ✨ ✨                │
│   const mintResult = await mintTokensForNewUser(                  │
│     walletAddress,  // "0x742d35Cc6634C0532925a3b844Bc9e7595f..."│
│     100             // 铸造数量                                    │
│   );                                                              │
│                                                                     │
│   if (!mintResult.success) {                                       │
│     console.warn("Warning: Minting failed:", mintResult.error);  │
│   }                                                               │
│                                                                     │
│   // ✅ 第 5 步: 返回响应给前端                                     │
│   res.status(200).json({                                          │
│     success: true,                                                │
│     user,  // 包含更新后的 walletAddress                           │
│     message: "Wallet connected successfully"                      │
│   });                                                             │
│ });                                                                │
└─────────────────────────────┬───────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────┐
│ 后端: utils/web3Service.js → mintTokensForNewUser()  ⭐⭐ 核心     │
│ ─────────────────────────────────────────────────────────────────── │
│                                                                     │
│ export const mintTokensForNewUser = async (                       │
│   userWalletAddress,  // "0x742d..."                             │
│   amount = 100        // 100 个代币                               │
│ ) => {                                                             │
│   try {                                                            │
│     // 🔧 第 1 步: 获取已初始化的智能合约实例                       │
│     const contract = getContract();                               │
│     // 这个 contract 由后端的私钥签名，拥有 mint 权限              │
│                                                                     │
│     // 🔧 第 2 步: 将代币数量转换为 Wei 单位                        │
│     const amountInWei = ethers.parseUnits("100", 18);            │
│     // 结果: "100000000000000000000" Wei                           │
│     // (因为 1 token = 10^18 Wei)                                 │
│                                                                     │
│     console.log(`Minting 100 tokens to ${userWalletAddress}`);   │
│                                                                     │
│     // 🔧 第 3 步: 调用智能合约的 mint() 函数                      │
│     const tx = await contract.mint(                               │
│       userWalletAddress,    // "0x742d..."                        │
│       amountInWei           // 100000000000000000000              │
│     );                                                             │
│     // 这一行执行后:                                               │
│     // - 后端私钥对交易进行签名                                     │
│     // - 交易被发送到 Sepolia 区块链网络                           │
│     // - 返回一个 Transaction 对象                                 │
│     // - tx.hash = "0x123abc..."  (交易哈希)                       │
│                                                                     │
│     // 🔧 第 4 步: 等待交易被确认（挖矿）                          │
│     const receipt = await tx.wait();                              │
│     // 这个 await 会一直等待，直到:                               │
│     // - 交易被矿工打包进一个区块                                   │
│     // - 区块被链接到区块链                                        │
│     // - 通常需要 15-30 秒                                        │
│                                                                     │
│     console.log(`Mint transaction hash: ${receipt.hash}`);        │
│                                                                     │
│     // 🔧 第 5 步: 返回交易成功信息                                │
│     return {                                                       │
│       success: true,                                              │
│       transactionHash: receipt.hash  // "0x123abc..."             │
│     };                                                             │
│   } catch (error) {                                               │
│     console.error("Mint error:", error);                          │
│     return {                                                       │
│       success: false,                                             │
│       error: error.message                                        │
│     };                                                             │
│   }                                                                │
│ };                                                                 │
└─────────────────────────────┬───────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────┐
│ 后端: config/web3Config.js → getContract()                          │
│ ─────────────────────────────────────────────────────────────────── │
│                                                                     │
│ // 全局初始化（应用启动时执行一次）                                 │
│                                                                     │
│ const SEPOLIA_RPC_URL = process.env.SEPOLIA_RPC_URL;             │
│ // = "https://sepolia.infura.io/v3/YOUR_INFURA_KEY"              │
│                                                                     │
```

## 🎯 关键的 4 个环节

```
环节 1: 注册账户
├─ 前端: Submit → authApi.register()
├─ 后端: registerUser() → User.create()
├─ 数据库: 保存用户 (walletAddress: null)
└─ 结果: 用户创建，JWT 返回，自动 getMe()

环节 2: 获取用户信息
├─ 前端: 自动调用 userApi.getMe()
├─ 后端: getUserProfile() 读取 MongoDB
├─ Redux: 保存用户信息到 Store
└─ 结果: 前端知道用户已登录，但 walletAddress 为 null

环节 3: 连接钱包 ← ⭐ 关键转折
├─ 前端: 用户点击"连接钱包" → MetaMask
├─ 中间: 用户授权选择账户
├─ 前端: 获取账户地址 → web3Api.connectWallet()
└─ 结果: 钱包地址发送给后端

环节 4: 铸造代币 ← ⭐⭐⭐ 代币产生处
├─ 后端: connectWallet() 验证并保存钱包地址
├─ Web3: mintTokensForNewUser() 调用智能合约
├─ 区块链: contract.mint() 执行，交易被确认
└─ 结果: 100 代币被铸造到用户 MetaMask
```

## ⚡ 性能和时间消耗

```
注册流程:
├─ registerUser() 创建用户: ~50-100ms (数据库操作)
├─ sendToken() 生成 JWT: ~1-2ms (加密)
├─ getMe() 获取用户: ~50-100ms (数据库查询)
└─ 总计: ~150-200ms (前端体验：瞬间完成)

钱包连接流程:
├─ MetaMask 弹出授权: 0-30秒 (用户决定)
├─ connectWallet() 验证和保存: ~50-100ms (数据库)
├─ mintTokensForNewUser() 构造交易: ~100-200ms (Web3 操作)
├─ contract.mint() 发送到区块链: ~500-1000ms
├─ tx.wait() 等待确认: ~15-30秒 (区块链挖矿)
└─ 总计: ~16-31秒 (大部分时间在等待区块链确认)
```
